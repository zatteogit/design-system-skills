Box - Rack

I box rack sono contenitori versatili, flessibili ed estensibili. A differenza delle Card, offrono una struttura più semplice e altamente personalizzabile. Gli elementi interni possono essere organizzati in base alle esigenze specifiche, sfruttando le proprietà di Flexbox del framework sottostante, minimizzando l'uso di stili inline se non strettamente necessari.

Un esempio di utilizzo sono i premi o le sponsorizzazioni all'interno dei Module.
